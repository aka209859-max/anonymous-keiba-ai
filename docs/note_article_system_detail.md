## 📊 システム全体像

### Phase 0: データ取得
**目的**: 過去レースデータの収集

**データソース**
- 地方競馬データベース（MySQL）
- 過去5年分（2020-2025年）
- 全14競馬場
- 総レース数: 約50万レース

**取得項目**
- レース情報（開催日、競馬場、距離、馬場状態）
- 馬情報（馬名、年齢、性別、馬体重）
- 騎手情報（騎手名、所属、勝率）
- 過去5走の成績（着順、タイム、上がり3F）

**実装**
```python
python scripts/phase0_data_acquisition/extract_race_data.py \
  --keibajo 45 --date 2026-03-05
```

---

### Phase 1: 特徴量エンジニアリング
**目的**: 生データを機械学習用に変換

**生成される特徴量（139種類）**

#### 1. 馬の基本情報（10項目）
- 年齢、性別、馬体重、馬体重変化
- 毛色コード、繁殖番号

#### 2. 過去走データ（60項目）
- 過去5走の着順、タイム、上がり3F
- 過去5走の距離、馬場状態、競馬場
- コーナー通過順位（4コーナー分）

#### 3. 距離適性（15項目）
- 今回距離 vs 過去平均距離
- 距離変更率
- 同距離での成績

#### 4. 騎手データ（20項目）
- 騎手勝率、連対率、複勝率
- 競馬場別勝率
- 馬との相性（過去の組み合わせ成績）

#### 5. レース条件（10項目）
- 競馬場コード、距離、馬場状態
- 天候、クラス、グレード

#### 6. 派生特徴量（24項目）
- 前走からの日数
- 連続出走回数
- 休養明けフラグ
- 距離適性スコア
- 馬場適性スコア

**実装**
```python
python scripts/phase1_feature_engineering/prepare_features_safe.py \
  45 2026 03 20260305
```

**欠損値処理**
- 過去走データなし → 0埋め
- 馬体重欠損 → 平均値補完
- 全項目欠損の馬 → 予測対象から除外

### Phase 3: 二値分類モデル
**目的**: 「勝つ/負ける」を予測

**アルゴリズム**: LightGBM  
**ターゲット**: 3着以内 = 1, 4着以下 = 0

**ハイパーパラメータ**
```python
params = {
    'objective': 'binary',
    'metric': 'binary_logloss',
    'num_leaves': 31,
    'learning_rate': 0.05,
    'feature_fraction': 0.8,
    'bagging_fraction': 0.8,
    'bagging_freq': 5,
    'max_depth': -1,
    'min_data_in_leaf': 20,
    'lambda_l1': 0.1,
    'lambda_l2': 0.1
}
```

**訓練データ分割**
- 訓練: 2020-2024年（80%）
- 検証: 2025年1-6月（10%）
- テスト: 2025年7-12月（10%）

**評価指標**
- AUC-ROC: 0.78
- 精度（Accuracy）: 72%
- 適合率（Precision）: 68%
- 再現率（Recall）: 65%

---

### Phase 4-1: ランキングモデル
**目的**: 着順を予測

**アルゴリズム**: LightGBM Ranking  
**ターゲット**: 着順（1位〜18位）

**特殊な設定**
- `group`: レースIDでグルーピング
- `label_gain`: 上位着順に高いゲイン

**評価指標**
- NDCG@3: 0.65
- Spearman相関: 0.58

---

### Phase 4-2: 回帰モデル
**目的**: 走破タイムを予測

**アルゴリズム**: LightGBM Regression  
**ターゲット**: 走破タイム（秒）

**正規化**
```python
normalized_time = (actual_time - distance_avg_time) / distance_std_time
```

**評価指標**
- RMSE: 1.2秒
- MAE: 0.8秒
- R²: 0.72

---

### Phase 5: アンサンブル
**目的**: 3モデルの予測を統合

**重み付け**
- 二値分類: 30%
- ランキング: 50%
- 回帰: 20%

**統合式**
```python
ensemble_score = (
    0.30 * binary_prob +
    0.50 * (1 - ranking_score / max_rank) +
    0.20 * (1 - normalized_time)
)
```

**ランク付け**
- S: スコア 0.80以上（最有力）
- A: スコア 0.70-0.79（有力）
- B: スコア 0.60-0.69（注目）
- C: スコア 0.50-0.59（穴）
- D: スコア 0.50未満（警戒）

---

### Phase 6: 購入推奨生成
**目的**: 馬券購入候補の提示

**推奨ロジック**
1. スコア上位3頭を「本命軸」
2. 4-7位を「相手候補」
3. 馬単・三連複の組み合わせ生成

**期待値計算**
```python
expected_value = win_prob * odds - 1
```

期待値 > 0.1 の組み合わせのみ推奨
